# Microbiome Feature Importance Visualization

This directory contains code and data for visualizing the relationships between gut microbiome features and nutritional variables using GraphLAN.

## Overview

The visualization represents machine learning feature importances for different bacterial species in relation to:
- Healthy Eating Index (HEI)
- Vegetables and Fruits consumption
- Oils and Nuts consumption
- Coffee consumption
- Meat consumption

The bacterial prevalence in the population is also included as an additional data layer.

## Files

- `generate_graphlan_plot.sh`: Script to generate the GraphLAN visualization
- `nutrition_features_tree.txt`: Contains the hierarchical structure of bacterial species
- `nutrition_features_annotations.txt`: Contains styling and data annotations for GraphLAN
- `nutrition_features_tree_annotated.xml`: Intermediate XML file generated by GraphLAN
- `nutrition_features_importance_plot.png`: Final visualization output
- `prep.ipynb`: Jupyter notebook for processing feature importance data and generates GraphLAN input files


## Usage

First, install GraPhlAn following the instructions at https://github.com/biobakery/graphlan
Then, to generate the visualization:

```bash
# Set the path to your GraphLAN installation
path_to_graphlan="../../graphlan"

# Generate the annotated XML
${path_to_graphlan}/graphlan_annotate.py --annot nutrition_features_annotations.txt nutrition_features_tree.txt nutrition_features_tree_annotated.xml

# Create the final plot
${path_to_graphlan}/graphlan.py nutrition_features_tree_annotated.xml nutrition_features_importance_plot.png --dpi 300 --size 8
```

## Visualization Features

The final plot includes:
- Hierarchical tree structure of bacterial species
- Color-coded taxonomic groups
- Multiple data rings showing:
  1. Taxonomy markers
  2. HEI importance (orange)
  3. Vegetables-Fruits importance (green)
  4. Oils-Nuts importance (indigo)
  5. Coffee importance (brown)
  6. Meat importance (red)
  7. Bacterial prevalence (cyan)

## Dependencies

- GraPhlAn
- Python libraries: pandas, numpy, matplotlib, seaborn

## Data Sources

- Feature importance data derived from classifier models
- Taxonomy information from QIIME2 processing
- Prevalence data of microbiota
